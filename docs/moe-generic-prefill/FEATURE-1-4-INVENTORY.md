## New learning foundation

The shared source-program helpers initialize full expert coverage even from a partial prior, validate routes before counting, preserve raw uint64 occurrence totals and accumulate double heat at the existing accepted decay boundaries. Recording observations while asynchronous adaptation is pending does not fold or decay heat. Snapshots do not mutate learning state. The owner retains these vectors in the existing grouped resource; the snapshot uses the same adaptation/mapping locks and live transaction check.

Accumulated heat remains the sum of accepted pre-decay usage, matching that part of specialized learning. Raw counts include every successfully joined source maintenance window, including pending-copy windows; they are not decayed. Tail counts after the last decay are retained even when heat has not folded them yet. A seed change starts a fresh learning epoch under the existing owner reset contract. No prefill/draft/accepted-prefix-only coverage is implied: current observations follow the existing target source-dispatch execution boundary.

The exported full ranking currently orders learned heat then complete prior ties. It does not force current residency to the front as Strata's saver does; this distinction must remain explicit in file provenance and held-out comparisons. The existing online swap/admission policy is unchanged. Final file format must preserve heat, counts, prior/tie behavior and snapshot provenance separately rather than pretending heat is raw frequency or confidence. Descriptor-wide context composition and guarded atomic file publication are now implemented; source/CPU/Linux publication evidence is in PROFILE-LEARNING.md. Opt-in production safe-boundary hooks and a generic same-model context-group snapshot are implemented with CPU link/test evidence. Physical multi-device, live owner/context/MTP and independent overlapping-history handling remain open.
